# 🎵 Music Center - Descargador de Música para el Centro de Acompañamiento

Software de escritorio fácil de usar diseñado para que los profesionales del centro descarguen música y audio desde YouTube de manera organizada y accesible para los jóvenes.

## 🌟 Características
- **Interfaz moderna y amigable**: Diseñada en modo oscuro relajante para fácil uso.
- **Formatos de Audio**:
  - `M4A`: Formato nativo rápido de alta calidad (compatible con reproductores modernos).
  - `MP3`: Formato estándar (con motor FFmpeg portátil incluido).
  - `WAV`: Calidad sin compresión.
- **Modos de Descarga**:
  - **Por Enlace Directo**: Soporta canciones individuales y **listas de reproducción (playlists)** completas.
  - **Buscador Integrado**: Permite buscar canciones por nombre o artista directamente sin necesidad de entrar a un navegador.
- **Organizador de Archivos**: Los archivos se guardan automáticamente en la carpeta `Música/Musica_Centro` del equipo con botón de acceso rápido.
